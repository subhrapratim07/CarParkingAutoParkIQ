# 🚗 AutoParkIQ – Automatic Parking Management System

🎓 **Final Year Project** | Department of Computer Science  
🔗 [Live Demo Portfolio](https://autoparkiq.netlify.app/)

---

## 🧠 Overview

**AutoParkIQ** is a real-time automatic parking detection and management system that integrates **Computer Vision**, **Machine Learning**, and **Web Technologies** to revolutionize the traditional parking experience.

---

## 🚀 Key Features

- 🎥 **Real-Time Camera Integration**  
  Uses live camera feed to detect available and occupied parking slots.
  
- 🧠 **ML-Powered Detection System**  
  Trained model using **TensorFlow** and **OpenCV** to identify parking occupancy with increasing accuracy.

- 🌐 **Web Dashboard**  
  Built with **React.js**, allowing users to:
  - View real-time parking status
  - Select and reserve slots
  - Get navigation to parking spot

- 💾 **Data Synchronization**  
  Slot status is continuously updated and stored in **MongoDB**, ensuring real-time availability tracking.

- 🧭 **Navigation Assistance**  
  Helps users navigate directly to their reserved parking space with minimal delay.

🛠️ How to Run Locally
Clone the repo
git clone https://github.com/subhrapratim07/AutoParkIQ.git
cd AutoParkIQ

Start Backend
- cd backend
- npm install
- npm start

Run ML Python Script
- python app.py

Start Frontend
- cd frontend
- npm install
- npm run dev
